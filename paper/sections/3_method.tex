\section{Method}
\label{sec:method}

\subsection{The audited system and protocol}

\sysname{} (Multi-Agent Discussion Framework) is a roundtable platform
in which each participant is an LLM agent conditioned by a persona skill
file. Each round proceeds as follows: every agent independently emits a
decision JSON \texttt{\{decision, confidence, reasoning\}}; the
orchestrator selects the agent with the highest confidence among those
choosing \texttt{speak}; if all agents wait, one is chosen at random
(forced speech). Confidence values pass through a hash-derived jitter
that preserves the tenths digit and replaces the hundredths digit with a
value derived from the agent's run identifier, preventing the model's
preference for round numbers. A host agent opens and closes the
discussion. We audited commit \texttt{2f1baa}. The bidding-for-the-floor
idea descends from importance-driven turn-bidding in spoken dialogue
systems~\cite{selfridge-heeman-2010-importance}; our audit concerns the
evaluation protocol, not the mechanism's novelty.

\subsection{Testbed: protocol-faithful reimplementation}

The reference implementation depends on an agent-graph framework, a
database, and a cache. To make every condition differ only in the factor
under study, we re-implemented the protocol as a headless testbed in
pure Python (standard library only). The system prompt (environment
description, persona framing, three iron rules, thinking and speaking
instructions, information-boundary rules), the decision schema, the
jitter algorithm, the arbitration rule, and the host prompts are
reproduced from the source. Documented deviations, applied identically
to all conditions and therefore invisible to comparisons: the
agent-graph is replaced by direct system-prompt calls (the reference
implementation already bypasses the graph for decisions); streaming is
replaced by single calls; persistence is omitted; persona skills are
authored by us because the reference implementation's skill volumes are
not in the repository; discussion duration is 120\,s with a floor of
three rounds. Fidelity was checked line-by-line against the source; the
full correspondence table is in the released repository. We therefore
describe the testbed as \emph{protocol-faithful} rather than verbatim:
the orchestration logic is reproduced exactly, while the surrounding
stack and the persona files are substitutions, and all conclusions are
scoped to the authored skills.

\subsection{Reasoning-model adaptation}

The protocol was designed for non-reasoning models. Running it
unmodified on a reasoning model (our primary driver) fails
\emph{silently}: chain-of-thought consumes the token budget so that the
decision JSON never appears, and the parser degrades the decision to
\texttt{wait} (all agents appear silent; every round becomes forced
speech); speech calls emit meta-narration instead of character speech;
and judge calls emit no parseable score, defaulting to 5.0. We fixed
this with per-call token budgets and reasoning-effort control, and parse
decisions from both output channels. The failure is not fully eliminated,
only bounded: across the 480 judged dimension calls, 28--30 per judge
still required regex fallback, and 22--26 per judge still defaulted to
5.0 (Appendix~\ref{app:quality}). We report this because any
replication of this protocol family on reasoning models must handle it,
and because silent degradation is itself a hazard for the evaluation
protocols under audit.

\subsection{Experimental design}

\paragraph{Judges.} Three judges score every transcript: two models of
the driver's vendor (a flagship reasoning model and a smaller
non-reasoning model) and one cross-vendor model (DeepSeek
\texttt{v4.1-flash}). All judges receive the audited system's own judge
prompts verbatim (five dimensions, 1--10, anchored rubrics,
pre-computed speaking-count statistics); only the judge model varies.
Temperature 0.1. A fourth judge (a third flash-class model of the
driver's vendor) was also run and is released with the artifact; it is
reported only as a robustness line, because its parse-failure rate is
roughly three times the others' (Appendix~\ref{app:quality}).

\paragraph{Discussions.} We analyze 32 discussions; one warmup
discussion present in the released transcript file is excluded from all
analyses. (i)~\emph{Factorial}: two drivers $\times$ two topics $\times$
two repetitions (8 discussions, full system) for the judge-identity
analysis. (ii)~\emph{Ablation replication}: the audited system's three
core conditions---full system, no arbitration (round-robin), no
jitter---each five repetitions (15 discussions) under the primary
driver. (iii)~\emph{Same-machine replication}: the same three
conditions, three repetitions each (9 discussions), under the secondary
driver, so that three judge identities---the driver's own model, a
same-vendor sibling, and a cross-vendor model---can be compared on
identical transcripts. Personas are fixed across conditions (three
public figures with disjoint expertise); topics are fixed across
conditions.

\paragraph{A defect in the audited judge prompt.} The audited judge's
pre-computed speaking-count statistic counts only agents that appear in
the transcript, so an agent that never speaks is omitted and the
reported maximum gap is underestimated: for counts $(2,1,0)$ it reports
gap 1 (applying the ``mechanical rotation'' cap) instead of the true
gap 2. This affects 7 of the 32 discussions. We preserve the audited
behavior in the main analysis---the prompt is part of the protocol under
audit, and the defect applies identically to every judge---and
re-judge the affected discussions with corrected statistics as a
robustness check (Appendix~\ref{app:robust}).

\paragraph{Mechanism metrics.} Judge-free structural metrics computed
deterministically from transcripts: speaking-count Gini coefficient
(over all three agents, zero-speech agents included) and
forced-speech rate. These describe discussion dynamics without invoking
any judge.

\subsection{Statistics}

Inter-judge agreement uses Spearman rank correlation (overall and per
dimension) and mean absolute difference. Condition comparisons report
the mean difference, Cliff's $\delta$ (non-parametric effect size),
bootstrap 95\% confidence intervals for the mean difference and for
$\delta$ (10{,}000 resamples, groups resampled independently), and an
exact two-sided permutation test on the difference of means (all
$\binom{n_1+n_2}{n_1}$ labelings; exact in the presence of ties). The
six ablation contrasts per phase (three judges $\times$ two ablations)
form the family for Holm correction; the correction was applied after
the audit revisions reported in this paper, so it is stated as post hoc
family-wise control rather than preregistered analysis. With
three-to-five repetitions per condition the exact test
has limited resolution---with $3\times3$ samples its minimum attainable
two-sided $p$ is $0.1$---and after Holm correction no ablation contrast
is significant; we therefore treat point estimates, effect sizes, and
intervals as the primary evidence and $p$-values as auxiliary, and we
make no significance claims for any single contrast. Self-preference is
estimated as the difference between same-driver and other-driver scores
under a fixed judge, with a stratified bootstrap interval (groups
resampled independently, sizes preserved) and an exact permutation
$p$-value over all $\binom{8}{4}$ labelings; this is an exploratory,
unblocked analysis on four versus four discussions and is
underpowered. Leniency offsets are
differences from the mean of the other judges on the same discussion,
bootstrapped over discussions. An auxiliary model (different family from the authors'
toolchain; not a blind review) reviewed the evidence-to-claim mapping;
its verdict and our responses are in Appendix~\ref{app:jury}.
