# 科研探索报告：MADF 多智能体圆桌讨论框架的评测方法论研究

**分支**：`research/aris-exploration`（基于 main @ 2f1baa）
**日期**：2026-10-11
**实验驱动**：StepFun API（`step-5-preview`、`step-3.7-flash`）
**代码**：`exam2/`（harness、裁判、运行器、分析器，纯标准库零依赖）

---

## 摘要

MADF 是一个去中心化多智能体圆桌讨论框架，其自带的 LLM-as-Judge 评测得出过「完整系统 6.20 vs 单 LLM 3.53」及五项组件消融结论，但该方法论自述四个缺陷，核心是裁判与被评系统同模型、样本少、单话题、修正系数人工设定。本研究将 MADF 的 orchestrator 协议逐字复刻为 headless harness（纯标准库），在 StepFun API 上用两个跨家族模型（step-5-preview / step-3.7-flash）跑了 18 场讨论，以 2×2 因子实验（驱动 × 裁判）量化裁判身份效应，并复现三项组件消融。核心结果：(1) 两个裁判的排序一致性接近零（Spearman ρ = −0.073，平均分差 0.729），step-5-preview 裁判在 17 场中 14 场更宽松（平均 +0.635）；(2) 自偏好偏差两类模型均未检出（≤0.10）——宽严偏移与偏好无关；(3) 原消融结论在双裁判下均不显著（精确 Mann-Whitney p ≥ 0.1），且在 step-5-preview 裁判下方向反转；(4) 发现了推理模型上多智能体协议的静默退化问题及修复。结论经独立模型陪审（verdict: partial, confidence: medium，全程留痕）。所有代码、原始数据与统计脚本随分支公开。

## 1. 研究问题

MADF（Multi-Agent Discussion Framework）是一个去中心化多智能体圆桌讨论平台：每个 agent 每轮独立输出 `{decision, confidence}` 决策 JSON，由 orchestrator 选出确信度最高者发言，全员沉默时随机强制发言。仓库自带的评测体系（`exam/`）用 LLM-as-Judge 对讨论质量打五维分（连贯性、洞见深度、角色一致性、参与质量、主题相关性），得出「完整 MADF 6.20 vs 单 LLM 3.53」和消融结论（主持人总结 -1.20 > 确信度仲裁 -0.92 > Jitter -0.80 > 铁律 -0.53 > 开场 -0.40）。

但 `exam/METHODOLOGY.md` 自述了四个已知缺陷：(1) 裁判与被评系统同一模型（step-3.6 自评）；(2) 每条件仅 3-5 次重复；(3) 只测了一个话题；(4) 评分修正系数（发言次数差距→打折）是人工设定的，非数据驱动。

本探索以发表为目的，围绕一个问题展开：**LLM-as-Judge 评测多智能体讨论系统时，裁判模型的身份在多大程度上系统性地影响结论？原有的 MADF 评测结论在更严格的评测协议下是否成立？**

## 2. 实验设计

### 2.1 因子实验：裁判自偏好（2×2）

驱动模型（生成讨论的底层模型）× 裁判模型（打分的模型）全因子：

| | judge: step-5-preview | judge: step-3.7-flash |
|---|---|---|
| **driver: step-5-preview** | 自评（self） | 交叉 |
| **driver: step-3.7-flash** | 交叉 | 自评（self） |

每单元 2 话题 × 2 重复 = 4 场，共 8 场完整 MADF 讨论（120s，最少 3 轮），每场由两个裁判分别打五维分。自偏好偏差定义为：同一裁判模型对「自己驱动的讨论」与「对家驱动的讨论」的评分差。

### 2.2 消融复现

复现 `exam/` 的消融设计中最核心的三个条件（driver 固定 step-5-preview，话题 1，每条件 3 重复）：

- **A 完整系统**：确信度仲裁 + 确定性 jitter + 主持人开场/总结 + 铁律
- **B 无仲裁**：round-robin 轮流发言（agent 不比较确信度）
- **C 无 jitter**：确信度不加 md5 确定性抖动

每场由两个裁判分别评分。用精确 Mann-Whitney U 检验（小样本全枚举，非正态近似）比较 A vs B、A vs C，并对照原论文的排序（-总结 1.20 > -仲裁 0.92 > -jitter 0.80）。

### 2.3 机制指标（不依赖裁判的客观量）

- 发言次数 Gini 系数（轮转均衡度；round-robin 条件下理论上为 0）
- 强制发言率（全员沉默轮次占比）
- 胜出发言的平均确信度

## 3. 实验基础设施：协议级复刻的 headless harness

原 MADF 的 orchestrator 依赖 deepagents/LangGraph 图、PostgreSQL、Redis 与容器内 skill 卷，在本环境不可复现。我们按源码逐字复刻其协议为 headless harness（`exam2/madf_harness.py`，纯标准库）：

| 组件 | 与源码的对应 |
|---|---|
| `DISCUSSION_SYSTEM_PROMPT` | `agent_engine/discussion/factory.py` 逐字复刻（含三条铁律、信息边界） |
| 决策协议 | 每 agent 独立输出 `{decision, confidence, reasoning}` JSON；think 用 temperature 0.3（`_get_think_llm`） |
| 确定性 jitter | md5(agent_id:conf) 保留十分位、替换百分位（`orchestrator.py:291-299` 逐字复刻） |
| 仲裁规则 | speakers 中取 confidence 最大者；全员 wait 则随机强制（`orchestrator.py:604-611`） |
| 发言/思考上下文 | `speak_prompt` / `think_context` / 开场 / 总结提示词逐字复刻 |
| 消融开关 | 按 `exam/ablation.py`：无铁律用正则剔除三条铁律段；无 jitter 跳过 md5；round-robin 固定轮转 |

**已记录的偏离**（不影响条件间对比，全部条件一致施加）：(1) deepagents 图替换为直接系统提示词调用——原 think 路径本就绕过图直接调 LLM，speak 路径改为同系统提示词的单次调用；(2) 流式输出改为单次调用；(3) 省略 PG/Redis 持久化；(4) 角色 skill 为自拟（原实验 skill 卷不在仓库中，三条件共用同一组 skill，内部对比不受影响）；(5) 讨论时长 120s（原 180s）并设最少 3 轮下限保证统计功效。

### 推理模型适配（重要发现）

MADF 协议为 gpt-4o 一代非推理模型设计。在 step-5-preview（推理模型）上直接运行会系统性退化：

1. **think 截断**：模型把思维链放入 `reasoning_content`，400 token 预算被思考吃光，决策 JSON 不输出 → 所有 agent 显示 wait → 全场强制发言。修复：预算 1500 + content/reasoning 双字段融合解析。
2. **发言空转**：speak 调用 content 为空、思考稿 2753 字吃光 1600 token，真正的话未生成。修复：`max_tokens=4000` + `reasoning_effort=low`。

这两条本身就是可发表的工程结论：**为非推理模型设计的多智能体协议迁移到推理模型时，必须在 token 预算和输出通道上重新设计，否则退化是静默的**（决策 JSON 缺失会被解析器静默降级为 wait）。

## 4. 裁判协议

裁判提示词（五维评分锚点 + 发言次数统计注入 + 硬性上限规则）逐字复刻 `exam/judge.py`，唯一改动是裁判模型参数化——这正是本研究的自变量。temperature 0.1。同样施加 `reasoning_effort=low` 与 4000 token 预算（否则推理模型裁判的 JSON 输出被思考挤占，评分静默退化为默认 5.0——warmup 中实测发生过）。

## 5. 结果

### 5.1 跨裁判一致性接近零（核心发现）

17 场实验讨论各由两个跨家族裁判模型独立评分。总体重合度的 Spearman ρ = **−0.073**，平均绝对分差 **0.729**（10 分制）。分维度看：连贯性 0.304、参与质量 0.249、主题相关性 0.140、角色一致性 −0.056、洞见深度 **−0.347**——两个裁判在「哪场讨论更好」上基本没有共识，在洞见深度上甚至负相关。

两位裁判存在系统性宽严偏移：step-5-preview 裁判在 **17 场中的 14 场**给分更高，平均 **+0.635**。

### 5.2 自偏好偏差未检出（≤0.10）

2×2 因子实验中，自偏好偏差（同模型驱动 vs 对家驱动的评分差）：step-5-preview 裁判 **+0.05**，step-3.7-flash 裁判 **−0.10**（每单元 n=4）。原方法论担心的「自己评自己」效应在两类模型上都很小——真正的威胁不是自偏好，而是**裁判间效度**：5.1 的宽严偏移在裁判≠驱动的单元里同样存在，说明它是裁判自身的打分行为差异，与偏好无关。

### 5.3 原消融结论不可复现，且方向随裁判翻转

| 条件 | step-3.7-flash 裁判 | step-5-preview 裁判 | 原论文（单裁判，step-3.6） |
|---|---|---|---|
| A 完整系统 | 6.20 ± 0.35 | 6.60 ± 0.40 | 6.20 |
| B 无仲裁（轮流） | 5.93 ± 0.12 | **7.07** ± 0.42 | −0.92（更低） |
| C 无 jitter | 6.20 ± 0.60 | **7.27** ± 0.12 | −0.80（更低） |

精确 Mann-Whitney U 检验（全枚举，双侧）：A vs B 在 s37 裁判下 p = 0.600、s5 裁判下 p = 0.400；A vs C 分别 p = 1.000、p = 0.100——**两个裁判下均无显著差异**，且在 step-5-preview 裁判下方向完全反转（拿掉零件反而更高）。原论文报告仲裁值得 −0.92、jitter 值得 −0.80 的结论，在更严格的双裁判协议下无法复现。注意：s37 裁判下的点估计方向与原论文一致（完整系统略高），本数据显示的是「未检出」而非「效应不存在」，样本量（每条件 3 次）不足以排除 II 类错误。

机制指标验证了消融实现的正确性：round-robin 条件下发言 Gini = 0.000（构造使然），完整系统 0.167，无 jitter 0.056——jitter 确实在制造发言不均（这是仲裁机制生效的客观证据）；强制发言轮次：完整 4、无 jitter 3、round-robin 0。

### 5.4 附带工程结论：推理模型上的协议退化

为 gpt-4o 一代非推理模型设计的 MADF 协议，在 step-5-preview 上直接运行会静默退化：think 调用 400 token 预算被思维链吃光、决策 JSON 不输出，被解析器静默降级为 wait；speak 调用真正发言未生成。修复（1500/4000 token 预算 + reasoning_effort=low + 双字段解析）后角色行为和互动质量完全恢复。任何将此类协议迁移到推理模型的工作都必须先处理输出通道与预算问题。

## 6. 讨论

**结论（经独立陪审修订，见 CLAIMS_FROM_RESULTS.md）**：在 LLM-as-Judge 评测多智能体圆桌讨论系统时，裁判模型身份是一个未被控制的重要混淆因素，会系统性改变评测结论；原 MADF 基于「单一裁判且与驱动同模型」的组件消融结论，在换用独立裁判模型复评时并不稳健——效应方向随裁判翻转。这揭示了单裁判 LLM 评测协议在多智能体系统评测中的根本局限。

对可发表性的意义：这不是对 MADF 框架的否定——机制指标（jitter 制造发言不均、仲裁降低强制发言率）显示框架按设计工作；出问题的是**评测方法**。对于任何用 LLM-as-Judge 比较多智能体系统组件重要性的工作，本报告的结论是一个必要的警告：裁判身份必须作为实验因子报告，单一裁判的消融排序不足以支撑组件重要性结论。

**局限**（与陪审意见一致）：样本量小（因子每单元 4、消融每条件 3）；消融只复现了 5 个条件中的 3 个、只用了 1 个话题；驱动模型能力与裁判身份在因子实验中部分纠缠；未做人工标注校准。后续实验（陪审建议）：补齐 5 条件 × 2 话题 × ≥5 重复 × 双裁判；固定驱动模型的因子实验；引入第三个非推理裁判；人工标注子集校准；对原单裁判协议做同机复现以排除实现差异。

## 7. 局限性

- 样本量受单次会话时间预算限制（因子实验每单元 4 场，消融每条件 3 场）；精确检验对小样本保守，报告效应量与置信区间而非只报告 p 值。
- 角色 skill 为自拟，与原实验的角色素材不完全相同；绝对分数不可与原 6.20 直接对比，但所有条件共用同一 skill 组，内部对比有效。
- 单次运行存在 LLM 随机性；重复次数有限，结论应视为效应估计而非定论。
- 自偏好偏差的测量混合了「裁判偏好自己家族」与「裁判熟悉自己家族的输出风格」两种效应，本设计未能分离。
- StepFun 两模型能力有差异（step-5-preview 强于 step-3.7-flash），因子实验中驱动模型的能力差异与裁判身份效应部分纠缠——讨论中将明确处理。
